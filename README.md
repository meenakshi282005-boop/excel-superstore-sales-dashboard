# excel-superstore-sales-dashboard
Interactive Sales Dashboard built in Microsoft Excel using Pivot Tables, Charts and Slicers
## Project Overview
This project focuses on analyzing Superstore sales data and building an interactive dashboard using Microsoft Excel.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- KPI Cards

## Dashboard Features
- Total Sales KPI
- Total Orders KPI
- Total Customers KPI
- Sales by Region
- Sales by Category
- Top 10 Products Analysis
- Sales by Segment
- Interactive Filters

## Key Insights
- West region generated the highest sales.
- Technology was the top-performing category.
- Consumer segment contributed the highest sales.
- Canon imageCLASS 2200 Advanced Copier was the best-selling product.
- California, New York, and Texas were the top-performing states.
